# Описание инструментов (Tool Schema) - Задание №2

1. **secure_calculator**
   - **Назначение:** Безопасное выполнение базовых математических расчетов.
   - **Входные параметры:** `a` (number), `b` (number), `operation` (string: add, subtract, multiply, divide).
   - **Ограничения:** Исключает выполнение произвольного кода (`eval`), работает строго с числовыми типами.

2. **query_local_db**
   - **Назначение:** Чтение данных из локальной базы данных SQLite.
   - **Входные параметры:** `query_text` (string).
   - **Ограничения:** Использует отдельное read-only соединение (`?mode=ro`), блокирует ключевые слова `DROP`, `DELETE`, `UPDATE`, `INSERT`.

3. **get_system_time**
   - **Назначение:** Получение актуальной даты и времени сервера.
   - **Входные параметры:** Отсутствуют.
   - **Ограничения:** Не принимает пользовательских аргументов, работает изолированно.
